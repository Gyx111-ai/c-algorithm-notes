## 1. 邦多利叠叠乐（栈模拟消消乐）
### 题目简述
依次放入元素，如果相邻两个属性相同，两者同时消失，上方元素下落。最后从下往上输出剩余元素。

### 一开始思路卡点
最开始直接想在原数组原地修改，发现删除元素后，后面元素前移很麻烦，下标很容易乱。
后面想到**辅助数组**（栈本质就是一个辅助数组）：
1. 辅助数组用来存放当前还保留的元素
2. 每次新来一个元素，先看辅助数组最后一个元素
    - 如果相等：把数组末尾元素删掉（相消）
    - 如果不等：把新元素放进辅助数组末尾
> 核心：只需要看栈顶，不用遍历整个数组，这就是栈的妙处。

### 踩坑记录
1. 字符串比较不能直接用 `==`，要用 `strcmp`
2. 输出时每个属性之间加空格，注意处理末尾多余空格
3. 二维char数组，数组名不用加`&`放入scanf；单个字符才需要`&`
4. 字符串末尾自带`\0`，数组长度要预留结束符位置

### 两种实现思路
- 思路A：栈（辅助数组）实现，推荐，代码简洁
- 思路B：原地数组修改，下标管理复杂，容易越界

## 2. 大数加法（辅助数组）
### 题目简述
C语言普通整型存不下超大数字，用字符串读入两个大数，模拟手工竖式加法。

### 核心思想
同样使用**辅助数组**，和叠叠乐是同一个思想：用额外空间保存结果，不破坏原始输入。
1. 两个数字字符串反转（低位对齐，方便从个位开始加）
2. 逐位相加，保存进位
3. 结果存入辅助数组，最后反转得到答案

> 感悟：大数加法、叠叠乐，两道完全不同的题，都用到辅助数组。
> 辅助数组本质：单独开辟一块空间，保存中间状态，避免修改原始数据带来下标混乱。

### 踩坑记录
1. 进位不要忘记处理，最高位相加后如果还有进位要额外补上
2. 字符转数字：`s[i] - '0'`，不要直接拿字符本身ASCII值计算
3. 注意前导零问题

## 3. 01背包 & 完全背包（动态规划、递推思想）
### 题目简述（原神药物背包题）
一共有x份药物，n个好友。打好友需要消耗药量，打赢获得经验，打输浪费药物。求最大经验。

### 核心概念理解
1. **状态定义**：`dp[j]` = 消耗不超过j份药，可以拿到的最大经验
2. **递推思想**：大问题的最优解，由更小规模子问题最优解推出
3. 二维dp：`dp[i][j]`，前i个物品，容量j的最大收益
    - `i-1`代表**不选第i个好友**（上一层旧状态，保证每个好友只能选一次，01背包）
4. 一维滚动数组优化：压缩二维数组，只用一维dp数组
    - 01背包：`j`从大到小倒序遍历。防止同一个好友重复选取
    - 完全背包：`j`从小到大正序遍历。允许重复选取同一个好友

> 关键感悟：
> 二维dp是原始完整模型；一维只是空间优化，底层逻辑不变。
> 01背包倒序，本质是保证更新dp的时候，用的是**上一轮i-1的旧数据**。

### 踩坑记录
1. 混淆01背包和完全背包循环顺序，一正一负差别巨大
2. dp数组初始化，初始状态要设置最低收益
3. 理解max：每一步在两个方案里面，保留收益更大的那一个

## 整体总结
1. **辅助数组**：栈消消乐、大数加法共用的工具，用来存放中间结果，简化逻辑。
2. **递推**：由小问题解推出大问题。斐波那契、行列式、DP背包底层都是递推，但程序实现侧重点不一样。
3. **动态规划**：二维是完整模型；一维滚动数组属于空间优化技巧，不是底层思想。
4. 学习路径：先理解逻辑，再写代码；不要只抄代码。写完复盘，思考有没有别的写法（数组改指针尝试）。
